# 故事板工作流与可复制说辞

仅在用户提供故事板、想从手绘草图制作故事板，或需要把故事板作为视频参考时读取。

## 工作流

1. 用户先手绘镜头关系，表达镜头顺序、起幅／落幅、人物位置、透视、视线和动作方向。
2. GPT 只整理空间可读性与动作节点，不把草图改造成最终角色设计或场景概念图。
3. 交付视频模型时，把整理后的故事板与正确的角色资产、场景资产一起使用。
4. 最终提示词中的【镜头内容】和【表演要求】继续负责具体动作、节奏与微表演。

若角色或场景资产中的高辨识度细节不正确，先修正资产。不要依靠文字否定错误图片。若故事板中存在旧时长或旧角色标签，使它们与最终提示词一致，或在整理阶段删除。

## 给 GPT：把手绘整理成导演控制故事板

```text
我将提供一张手绘故事板。请将它整理成一张供视频生成模型读取的“导演控制故事板”，不是最终画面，也不是角色或场景概念图。

请严格保留原手绘中的：

- 镜头数量与先后顺序；
- 每个镜头的起幅、过程和落幅；
- 摄影机高度、水平角度、俯仰角度与运动方向；
- 前景、中景、后景的空间关系；
- 角色A、角色B的相对位置、朝向、视线关系与入画方向；
- 场景透视、物件比例和动作发生的位置。

请帮助我丰富：

- 更清楚的人物轮廓和身体朝向；
- 更准确的空间透视与物件大小；
- 明确的前后景遮挡关系；
- 动作起点与结束状态；
- 摄影机运动、人物运动和焦点转移的方向；
- 每个镜头之间可以被连续理解的空间关系。

角色只使用容易区分的简化占位形象，不设计具体五官、发型、服装和饰品。环境只需表现空间结构、透视和主要物件，不添加具体材质、光影风格和装饰细节。

不要改变原来的事件顺序，不要自行增加镜头、人物、动作或剧情。不要把草图改成电影成片、概念插画或精细角色设计。

输出一张结构清楚的多格故事板，所有画格比例统一，按照从左到右、从上到下的顺序排列。画面内不要生成时长、对白、说明文字、水印或复杂标签，避免这些信息干扰后续的视频生成模型。
```

## 给视频模型：说明故事板职责

```text
【故事板说明】

@图……是本次视频的导演控制故事板，只用于明确：

- 镜头数量与事件先后顺序；
- 每个镜头的起幅、过程和落幅；
- 景别、摄影机高度、观察角度与运动方向；
- 前景、中景、后景的空间层次；
- 角色之间的相对位置、入画方向和视线关系；
- 场景透视与物件比例；
- 动作发生的关键节点。

故事板中的人物只是位置和动作标记，不用于确定角色的脸型、发型、服装、饰品和身体细节，也不要求复制其中的具体肢体姿势。

故事板中的环境只是空间示意，不用于确定最终场景的材质、光影、色彩和美术风格。

最终角色外观以对应的角色参考图为准；最终环境以场景参考图为准；角色的具体动作、微表情和镜头节奏以【镜头描述】和【表演要求】为准。

如果故事板与专门的角色参考图、场景参考图或文字镜头描述发生冲突，以专门参考图和文字镜头描述为准。
```
