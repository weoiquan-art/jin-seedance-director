# JIN Seedance Director

A practical director-style methodology for writing, revising, and diagnosing Seedance 2.0 / 2.5 video prompts.

It turns creative ideas into structured, continuity-aware, and self-checked prompts for short clips and multi-shot narratives.

## What It Covers

- 8–10 second clips and 15–30 second narratives
- Character, scene, camera, action, and audio continuity
- Long takes, transitions, POV interaction, chases, fights, product videos, and OOTD
- Prompt revision, failure diagnosis, and A/B testing

## Repository Structure

- `SKILL.md` — core workflow, delivery rules, and quality checks
- `references/` — 14 focused methodology, template, and diagnostic sections
- `scripts/self_check.py` — structural and key-rule self-check
- `agents/` and `assets/` — skill configuration and visual assets

## How to Use

1. Start with `SKILL.md`.
2. Provide your goal, duration, characters, reference assets, and constraints.
3. Use the skill to draft prompts, continue accepted shots, diagnose failures, or run A/B tests.

## Note

This repository documents JIN's project methodology and practice rules. It is not official Seedance documentation.
