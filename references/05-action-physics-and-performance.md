# 05｜动作物理、技能与人物表演

用本区把动作名翻译成可见因果，控制重心、接触、惯性、道具和人物表演。

## 目录

- 动作因果链

## 动作因果链

内部使用：

> 外部刺激 → 角色意图 → 身体准备 → 发力／位移 → 接触或落空 → 惯性收束 → 新的稳定状态

最终提示词只保留会改变执行、可读性、连续性或物理结果的节点。

动作名不是动作。例如“优雅地挥剑”缺少：

- 从哪里开始；
- 哪只脚支撑；
- 髋、肩和手臂怎样传力；
- 剑走什么路径；
- 接触什么；
- 结束时身体和剑在哪里。

## 可见节点与内部推演

内部可以逐关节、逐重心推演；最终不要把所有解剖细节倒入提示词。

保留节点的判断：

- 观众能否看见；
- 模型是否会因省略而误读；
- 是否决定方向、速度、接触或结果；
- 是否决定下一阶段起点；
- 是否能区分角色身份化动作。

30 秒需要更多可见节点，不等于更多关节术语。每个节点仍只承担一个主要变化。

## 起因—过程—结果

每个主要动作至少写：

### 起因

- 看见、听见、受到碰撞、被呼唤、发现目标或做出决定。

### 过程

- 身体准备；
- 运动方向；
- 速度变化；
- 与道具或环境的接触；
- 摄影机如何保留可读性。

### 结果

- 目标物发生什么；
- 人物停在哪里；
- 重心和姿态怎样收束；
- 环境留下什么反馈；
- 下一动作从哪个状态开始。

## 重心、支撑与接触

真实动作至少检查：

- 支撑脚是否承重；
- 发力脚是否蹬地；
- 髋部是否带动躯干；
- 手和道具是否有接触面；
- 受击对象是否有反作用；
- 落地时膝、髋或身体是否吸收冲击；
- 结束姿势是否能保持平衡。

禁止：

- 脚底滑行；
- 身体无准备瞬间加速；
- 手穿过物体；
- 武器与手分离；
- 力量没有目标反馈；
- 动作结束突然冻结。

## 速度、幅度、顺序与持续

只有会改变画面的量化才写：

- 速度：缓慢、突然加速、短促、持续冲刺；
- 幅度：小幅转头、完整转身、手臂大幅挥动；
- 顺序：眼睛先动、头随后、肩胸最后；
- 持续：停顿约半秒、保持一秒、连续两步。

不要默认写毫米、精确角度或每帧轨迹。微表情尤其避免毫米级肌肉控制。

## 转身

完整转身的内部顺序：

> 脚 → 髋 → 躯干 → 肩 → 头 → 视线

只在转身是主事件或模型反复误读时展开关键链条。

奔跑中回头：

- 眼睛与头先转；
- 肩胸小幅跟随；
- 骨盆与双腿保持原奔跑方向；
- 头发、衣摆和道具因惯性滞后；
- 看完后视线和头回到前方，不让身体无因反向。

## 技能动作

使用前摇—核心—后摇：

### 前摇／准备

- 确认目标；
- 调整脚步与重心；
- 手或武器到位；
- 环境只出现轻微预兆。

### 核心动作

- 发力部位；
- 动作路径与方向；
- 接触点或落空；
- 特效由动作或接触触发；
- 目标出现主要结果。

### 后摇／结果

- 肢体随惯性回收；
- 双脚或身体重新稳定；
- 特效逐渐消散；
- 目标和环境保留受力结果；
- 停在下一动作可用的状态。

武器 + 超能力时，不要让身体、武器和特效各自行动。特效的出生点、方向、速度和消散都跟随武器或接触。

## 多角色互动

多人场景先定义：

- 每个角色的身份和位置；
- 谁发起、谁反应；
- 接触发生在哪个身体或物体上；
- 谁的道具属于谁；
- 反应先后；
- 最终距离关系。

避免同刻给所有角色相同权重的主动作。推荐：

1. A 发出刺激；
2. B 出现主要反应；
3. C 只做必要的次级反应；
4. 摄影机跟随中心事件；
5. 结尾重新锁定人数和位置。

每次主体切换前重新写 @角色名。

## 二级运动

二级运动证明质量和速度：

- 头发和衣摆因身体加速滞后，再受限回摆；
- 旅行袋、挂带或武器受重量影响；
- 尘土、水花、纸张和草叶由真实接触或气流触发；
- Q 角色与真实物体互动时保留阴影、压痕、遮挡和碰撞；
- 不把所有附件做成同相位、同幅度摆动。

## 表演与台词

表演从刺激开始，不只写情绪标签。

通用情绪链：

> 刺激 → 无意识泄露 → 主动压制或选择 → 新的稳定状态

台词或拟声应绑定：

- 吸气、停顿或发力；
- 口型与下颌运动；
- 说话时的视线对象；
- 说完后的嘴唇、呼吸和目光；
- 摄影机距离与声音方位。

不要把复杂动作、快速运镜、长台词和细微表情同时设为主任务。

## 常见失败

| 失败 | 主要原因 | 第一修正 |
|---|---|---|
| 动作变成姿势展示 | 缺少触发、路径或结果 | 补一个完整因果弧 |
| 脚滑 | 没有支撑、蹬地和重心 | 写脚与重心，不加更多风格词 |
| 武器漂移 | 归属和持握不清 | 明确哪只手、运动路径和结尾 |
| 技能凭空出现 | 特效早于动作 | 让身体或接触触发 |
| 动作突然冻结 | 缺少后摇 | 加惯性回收和稳定状态 |
| 多人肢体融合 | 同刻主动作过多 | 分配先后和接触主体 |
| 表情抽搐 | 节点过多、过细 | 保留一次泄露、一次压制和结尾 |
