# 07｜长镜头、隐藏转场与续写

用本区设计连续镜头、视觉接力、跨空间运动和下一段延续。长镜头不是默认更优，只在连续性收益大于复杂度时使用。

## 何时使用长镜头

适合：

- 一个中心事件沿连续空间推进；
- 人物位置与惯性必须持续；
- 追逐、奔跑、战斗或互动需要沉浸感；
- 转场媒介本身具有叙事意义；
- 用户提供连续运镜参考。

不适合：

- 五个独立事件互相竞争；
- 多个地点没有自然连接；
- 身份稳定性比空间连续更重要；
- 关键表演需要独立特写；
- 单次生成难以可靠完成不可失败的转场机关。

“长镜头一定比分镜稳定”已经作废。真正目标是避免无动机状态重置。

## 三条连续性链

### 人物动作链

下一动作由上一刻的刺激、姿态、位置、速度和结果触发。

### 摄影机运动链

摄影机因为观察对象、视线、动作轨迹、障碍或目标而移动。

### 空间转换链

> 场景 A → 接力媒介进入 → 覆盖／模糊／过曝 → 状态转换 → 场景 B 显露

三条链共享同一时间线。缺任何一条，长镜头会变成多个场景的文字拼贴。

## 长镜头的隐藏分镜

长镜头仍有内部镜头节拍：

1. 建立人物与空间；
2. 触发中心动作；
3. 摄影机跟随或落后；
4. 前景／道具／暗部形成接口；
5. 接口后继承人物与镜头状态；
6. 新空间或新阶段显露；
7. 结果收束。

最终可按自然时间段写，不一定打印“镜头一／镜头二”。

## 视觉接力媒介

| 媒介 | 物理路径 | 适用 |
|---|---|---|
| 墙、柱、门框 | 实体从一侧进入前景，逐渐覆盖后从另一侧离开 | 空间或时间转换 |
| 人物背部、披风、人群 | 角色自然经过并填满画面 | 跟拍、战斗、群体 |
| 电话、书、刀、道具 | 镜头跟随或贴近表面 | 物件连接剧情 |
| 甩镜、快速转头 | 方向性运动模糊降低视觉信息 | 保持动作方向的接口 |
| 暗部、黑衣、隧道 | 暗区填满画面后从另一暗区离开 | 悬疑、低光 |
| 强光、爆炸、火焰 | 短暂过曝隐藏状态替换 | 异化、技能、梦境 |
| 地面、桌面、墙面 | 纹理占满画面，从另一表面继续 | 上下空间、倒地、穿越 |

媒介必须从场景和动作中自然出现，不为转场凭空生成。

## 遮挡转场

写清：

- 遮挡物从哪里进入；
- 与摄影机谁在运动；
- 如何覆盖主体；
- 覆盖期间人物继续做什么；
- 从哪里离开；
- 解除后人物真实位置；
- 前后姿态、速度、视线、道具和镜头方向。

不要把“某一帧 100% 完全遮挡”当成单次生成可保证的精确机关。若遮挡点承担不可失败剧情，扩大接口容错或保留后期剪辑余地。

已经成功的遮挡提示词继续保护，不因理论降级而被改写。

## 甩镜、暗部与强光

### 甩镜

- 前后保持同一主要运动方向；
- 运动模糊来自快速转向；
- 模糊后摄影机在可解释的新方向完成；
- 不用甩镜掩盖人物无因换位。

### 暗部

- 暗区来自真实墙面、衣物、隧道或阴影；
- 进入与离开路径清楚；
- 光源方向在接口后合理。

### 强光

- 过曝由太阳、爆炸、火焰、技能或灯具触发；
- 人物姿态和运动趋势在白场前后继承；
- 新空间逐渐恢复，不瞬间贴图。

## 五空间高速穿越

这是高级特殊模板，不是普通 2.5 默认。

保留的成功机制：

- 全片一个强运动主轴；
- 人物姿态、速度和惯性锁定；
- 每个空间都有入口物质；
- 有立体通道与必经地标；
- 有一个短微交互；
- 有出口物质；
- 破入后可短暂动态慢动作，再加速；
- 前中后景视差、气流／粒子方向和动态光共同证明速度。

不要机械复制某个成功案例的园林、纸钱、竹林或牡丹。迁移的是结构，不是具体物件。

固定运动轴、隐藏转场和长镜头优先仍属于项目策略，需要按新任务 A/B；不得写成官方 2.5 机制。

## 何时分段或硬切

选择分段生成：

- 每个事件都需要独立身份或动作控制；
- 中间状态可作为清楚尾帧；
- 转场对剧情不是核心；
- 单次生成失败成本高；
- 需要分别修复某一段。

选择明确硬切：

- 时间或地点跳跃本来就是叙事语言；
- 没有自然视觉接口；
- 隐藏转场会抢中心事件；
- 用户要求多镜头剪辑。

不要用“无缝”掩盖缺少物理连接。

## 续写工作流

1. 查看已接受成片或尾帧。
2. 记录人物、道具、摄影机、空间、光线、声音和未完成惯性。
3. 将真实结果写成下一段起始状态。
4. 只定义一个新的中心事件。
5. 保留上一段仍在工作的身份和镜头规则。
6. 写新的明确结束状态。
7. 加入针对续写跳变的失败保险。

续写模板：

> 【已接受尾帧】@角色 位于……，面向……，视线……；右／左手持有……；摄影机位于……，景别……，仍向……移动；主光从……照入；上一动作的……惯性仍在持续。
> 【下一段唯一任务】从这个真实状态继续，@角色 因……完成……，最后停在……。

## 常见失败与修正

| 失败 | 主原因 | 第一修正 |
|---|---|---|
| 接口前后人物瞬移 | 遮挡期间没有持续位移 | 明确速度、方向和重捕位置 |
| 新空间像贴图 | 缺少立体通道与视差 | 增加入场路径、地标和前景 |
| 长镜头中段变软 | 事件密度不足 | 补有动机的可见节点与结果 |
| 场景多但没有叙事 | 没有中心运动主轴 | 删场景或统一主轴 |
| 续写回到计划状态 | 未看真实尾帧 | 以成片实际状态重写起点 |
| 转场抢走动作 | 接口过复杂 | 简化媒介，保住中心事件 |
| 甩镜后方向翻转 | 前后运动轴未继承 | 写明进入和离开方向 |

## 长镜头自检

- 是否真的需要长镜头？
- 全片是否只有一个中心事件或主运动轴？
- 人物、摄影机和空间三条链是否连续？
- 每个接口是否来自场景？
- 遮挡期间人物是否继续移动？
- 接口前后姿态、速度、视线、道具和光线是否继承？
- 每个阶段是否有可见结果？
- 是否把帧级遮挡当成保证？
- 真实尾帧是否覆盖原计划？
