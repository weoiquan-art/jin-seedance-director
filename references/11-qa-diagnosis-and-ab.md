# 11｜生成前自检、成片诊断与 A/B

用本区在发送提示词前做硬门禁，在成片后只定位一个主故障，并保护已工作的结构。

## 生成前硬门禁

任一项不满足就先修正：

1. 平台、版本、生成方式、时长和画幅已知或已合理声明。
2. 一个中心事件能用一句话说清。
3. 起始人物、道具、摄影机和空间状态明确。
4. 主要动作有起因、过程、物理／情绪结果和结束状态。
5. 人物路线与摄影机路线能分别画出。
6. 每项参考素材有职责、不继承项和优先级。
7. 人数、身份、服装和道具归属不冲突。
8. 光源、声音和特效有真实因果。
9. 台词／拟声权限符合当前角色规则。
10. 最终提示词以【反向约束与失败保险】收尾。

## 提示词结构检查

### 版本一致

- 2.0 默认短镜头是否没有被无必要塞成多事件长叙事？
- 2.5 长时段是否有阶段继承和全时间覆盖？
- 是否把生产默认值误写成官方能力上限？

### 动作一致

- 每个动作是否只有一个明确主体？
- 起始姿态、路径、接触和结尾是否完整？
- 同一时刻是否存在不可能同时完成的命令？
- 内部关节推演是否被压缩成可见节点？

### 摄影机一致

- 摄影机是否有一个主要任务？
- 人物路线和镜头路线是否分开？
- 景别变化是否有可见过渡？
- POV 是否保持稳定观察？

### 连续性一致

- 阶段之间是否继承位置、朝向、速度、视线、道具和镜头？
- 遮挡期间主体是否继续移动？
- 光和声音是否随空间变化？
- 续写是否以真实尾帧开始？

### 输出一致

- 中文导演描述和角色实际声音是否正确路由？
- @角色名是否统一？
- 负面限制是否只有 5–6 条高风险项？
- 是否存在重复、装饰性或互相矛盾指令？

## 时长覆盖检查

### 8–10 秒

- 约 2–4 个可见节点；
- 一个中心动作；
- 一个主运镜；
- 结尾结果有短暂停留。

### 15 秒

- 约 2–3 个主要阶段；
- 每阶段一个主要变化；
- 有清楚的阶段结束状态；
- 追逐等复杂任务不过量叠加遮挡和拉焦。

### 30 秒

- 约 9–12 个可执行节点；
- 节点通常约 2–4 秒；
- 每约 10 秒内部段落有起点、行动、摄影机任务和结果；
- 没有大段只站立、展示或重复同一动作；
- 节点之间继承状态；
- 不为凑数添加无因事件。

## 十维成片验收

| 维度 | 检查内容 |
|---|---|
| 身份 | 脸型、五官、发型、年龄感、体态、气质是否稳定 |
| 数量 | 是否有额外人物、分身、错误反射或重复实体 |
| 动作 | 主动作弧是否完整；是否滑行、重置、瞬移或畸形 |
| 道具 | 数量、归属、持握、重量和接触是否连续 |
| 空间 | 位移是否真实；有无视差；遮挡后位置是否合理 |
| 摄影机 | 运动是否有任务和物理来源；景别是否有过渡 |
| 光影 | 受光是否服从场景；是否闪烁、跳影或贴图 |
| 声音 | 台词、口型、拟声、音效、环境和距离是否同步 |
| 表演 | 刺激、泄露、压制、选择和稳定状态是否可读 |
| 结尾 | 最终状态是否清楚，能否收束或承接下一段 |

不要用总分掩盖致命故障。身份错、人数错、主动作错或结尾错时，即使风格漂亮也不通过。

## 预期与实际对照

诊断时按以下顺序：

1. 从提示词提取必须发生的中心事件和结束状态。
2. 只描述成片中实际可见内容，不用意图替结果辩护。
3. 找出对观众理解影响最大的一个偏差。
4. 判断偏差属于身份、动作、道具、空间、镜头、光、声、表演还是结尾。
5. 选择一个最小修正杠杆。
6. 明确保留哪些有效结构。

输出格式：

> 预期：……
> 实际可见：……
> 唯一主故障：……
> 本次只改：……
> 保持不变：……

## 常见故障矩阵

| 观察问题 | 第一修正杠杆 | 先不要动 |
|---|---|---|
| 脸／服装漂移 | 统一人物锚点；减少竞争人物图；强化归属 | 动作、光影、镜头风格 |
| 额外人物／分身 | 锁定数量；排除镜面、海报和多视图误读 | 主动作和色调 |
| 动作被误读 | 补起始姿态、方向、主轴和结束状态；删次动作 | 增加形容词与特效 |
| 脚底滑行 | 写支撑、蹬地、重心和真实位移 | 镜头型号和气氛词 |
| 摄影机替人物动作 | 分开两条路线；减少运镜种类 | 角色外观和场景 |
| 长视频中段变软 | 增加可见节点和阶段结果；压缩空白 | 同时增加负面词 |
| 遮挡后瞬移 | 写遮挡期间持续位移和真实重捕位置 | 遮挡物类型与色调 |
| 手／武器畸形 | 降低手指精度、并行动作和人数；写整体轨迹 | 增加握柄特写 |
| 道具换手／脱手 | 明确哪只手、持握和最终归属 | 光线和背景 |
| 光影闪烁 | 固定真实光源、方向和遮挡变化 | 再加第二、第三主光 |
| 特效抢动作 | 让身体／接触触发；缩短效果 | 重写身份 |
| 微表情抽搐 | 保留一次泄露、一次压制和稳定结尾 | 毫米参数和更多情绪 |
| 声音忽远忽近 | 按距离、朝向和遮挡重写声场 | 画面动作与角色图 |
| 口型／声音错属 | 每名角色单独音频行并绑定动作 | 摄影机路线 |
| POV 情绪抖动 | 删除主观反应，只留真实外因运动 | 角色互动 |
| 续写跳变 | 以真实尾帧重写起点 | 原计划尚未发生状态 |
| 结尾含糊 | 写人物、道具、镜头、光声最终状态和停留 | 前半段有效结构 |

## 最小改动协议

1. 保存原提示词、素材顺序、平台、版本、时长、画幅、设置和成片。
2. 用一句话命名主故障。
3. 选择一个杠杆。
4. 只改控制该杠杆的最小段落。
5. 其余有效结构原样保留。
6. 对比新旧结果。
7. 有效则升级经验；无效则回滚，测试下一个杠杆。

禁止一次同时换人物图、动作、机位、光线、时长和负面词。

若用户已经说“通过”，除非明确要求变体或修复，不启动最小改动协议。

## A/B 测试

每次 A/B 一次只改一个主变量。

记录字段：

- 任务：平台、版本、入口、时长、画幅、生成方式；
- 原版本；
- A 与 B 的唯一差异；
- 固定素材与设置；
- 身份、动作、空间、镜头、光、声、表演、结尾的观察；
- 新故障；
- 成功／无改善／退化；
- 是否纳入项目稳定经验。

有效变量示例：

- 是否统一人物锚点；
- 遮挡期间是否明确持续位移；
- 30 秒是否增加时间覆盖节点；
- 微表情是否从四个泄露动作缩到一个；
- 镜头是否从环绕改为单一跟拍。

无效 A/B：

- 同时换提示词、素材、版本和时长；
- 只比较一个幸运样本；
- 没有保存原设置；
- 用主观“更电影感”代替可见指标。

## 黄金版本归档

优秀成片配对保存：

- 原提示词；
- 素材文件与顺序；
- 平台、入口、版本；
- 时长、画幅和设置；
- 生成日期；
- 中心事件；
- 成功点；
- 已知缺陷；
- 可迁移机制；
- 不应轻易修改的部分。

黄金成片的证据优先于文字洁癖。新理论可以解释成功，不得反向否定已发生的成功。

## 自检输出格式

最终提示词后可附简洁自检：

> 【自检结果】
> - 版本与时长：通过／阻塞，原因……
> - 中心事件与动作密度：通过／阻塞，原因……
> - 身份、人数、道具：通过／阻塞，原因……
> - 时空与摄影机：通过／阻塞，原因……
> - 光影、特效与声音：通过／阻塞，原因……
> - 角色台词／拟声权限：通过／阻塞，原因……
> - 结尾与续写状态：通过／阻塞，原因……
> - 【反向约束与失败保险】：已包含／缺失。

只报告会影响交付的事项，不输出隐藏推理过程。
